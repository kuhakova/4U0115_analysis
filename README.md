# 4U0115_analysis

This repository holds code and example data used for a part of timing and spectral analysis of 4U 0115+63. The whole work is done using several HEASoft tools (nupipeline, nuproducts, xspec), so this Python skript is only a part of the reseacrh. The functions, defined at the beginning of the code, (_cutting_ and _efoldin_) could be useful to perform pulse-intensity-resolved spectroscopy and timing analysis on other data.
